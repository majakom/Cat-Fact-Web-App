# Cat-Fact-Web-App

A web app written with the use of .NET MVC. App uses API to gather data with fun facts about cats and saves it locally to a txt file. 
Extra function: Entity Framework based database with sqlite that appends generated fun facts and stores them. App contains a button for drafting all data from database and downloading it for the user as a JSON file.
